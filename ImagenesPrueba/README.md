# Imágenes de prueba

Fotos del equipo del proyecto usadas para probar la reconstrucción del autómata. Sirven como ejemplos rápidos para cargar en la aplicación web sin tener que buscar imágenes.

---

## Cómo usarlas

1. Arranca la aplicación web (ver [`../Codigo/`](../Codigo/) o [`../Codigo/nca-web/README.md`](../Codigo/nca-web/README.md)).
2. En el navegador, haz clic en **load image** y elige cualquier `.jpeg` de esta carpeta.
3. La imagen se recorta automáticamente al cuadrado central y se redimensiona a 100 × 100.
4. Pinta con el pincel la zona que quieras borrar y pulsa **reconstruct**.

> Funciona mejor con rostros centrados y bien iluminados, porque el modelo fue entrenado con el dataset CelebA (rostros).
