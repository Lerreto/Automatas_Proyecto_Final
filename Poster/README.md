# Poster

Póster de presentación del proyecto **Reconstrucción de Imágenes Faciales con Autómatas Celulares Neurales** — Autómatas y Lenguajes Formales, Universidad Industrial de Santander.

---

## Archivo

`Poster.png` — póster del proyecto en formato imagen, listo para imprimir o proyectar.

Resume de forma visual y en un solo vistazo: el problema (*in-painting*), la idea del autómata celular neural, la arquitectura del modelo y los resultados.

Ábrelo con cualquier visor de imágenes.
